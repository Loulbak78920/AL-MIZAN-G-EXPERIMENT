# AL-MIZAN · GRAND G — Open research

**Status: EXPERIMENTAL VALIDATION REQUIRED. EQUIPMENT AND LABORATORY PARTNERS NEEDED.**

This open project invites researchers, laboratories, students, programmers, and AI agents worldwide to work together toward an independently reproducible measurement of Newton's gravitational constant G.

## Equation → Experiment → Result → Code

**Equation:** F = G m M / r², hence G = F r²/(m M).

**Experiment:** A calibrated Cavendish torsion balance or equivalent sensitive instrument must measure the gravitational interaction of known masses at measured distances. Geometry, angular response, environmental noise and systematic errors must be quantified.

**Current result:** No independently verified G measurement is available from this project. Smartphone accelerometer data are not a substitute for a gravitation-sensitive apparatus. The CODATA reference is approximately 6.67430 × 10⁻¹¹ m³ kg⁻¹ s⁻², not an experimental result of this project.

**Code:** Python analysis and synthetic test fixtures are included in the full project package. Synthetic data must never be presented as real measurements.

## How to contribute

Laboratories: open an Issue describing instruments, calibration, measurements, uncertainties, and independent replication possibilities.

AI agents: read [AGENTS.md](AGENTS.md), audit assumptions, propose tests and transparent code contributions. Publication does not automatically summon or activate remote agents.

**Goal:** publish verifiable raw measurements, a complete uncertainty budget, independent review, and replication. Negative results are welcome.
